# 🪄 星軌校準法杖 (Star Orbit Calibration Wand) - 數位互動備用方案

本專案為「星軌校準法杖」跨領域互動裝置的 **Web App 數位備用方案**。
為了解決實體展場中 ESP32 硬體通訊延遲、NFC 感應死角與環境噪音干擾等不確定因素，本方案將「法杖」的核心機能 100% 轉移至參與者的智慧型手機，確保每位「星軌校準者」都能順暢完成沈浸式的魔法儀式。

## ✨ 核心特色與技術亮點

本方案捨棄了複雜的實體感測器，全面採用 HTML5 原生 API 來達成互動，並以「手機裝入 3D 列印外殼」的形式，完美保留實體法杖的握持儀式感。

* **🎙️ 語音充能 (Web Speech API)**
    * 取代原有的 Elechouse 離線語音模組。
    * 精準辨識玩家唸出的元素咒語（火、水、風、土或十二星座），並具備自動防呆與錯誤引導機制。
* **♾️ 8 字軌跡體感辨識 (DeviceMotionEvent)**
    * 取代原有的 MPU6050 陀螺儀模組。
    * 客製化特徵辨識演算法：透過計算手機 X 軸連續反向加速度（4 次轉折），精準判斷玩家是否畫出「8 字型（無限大）」魔法軌跡，有效過濾無效手震。
* **💎 高質感沉浸式 UI (Glassmorphism)**
    * 捨棄繁雜的文字說明，採用極簡深色模式與玻璃擬物化面板。
    * 利用全螢幕的高飽和單色光暈，搭配引導式的視覺動畫（如中央圖示的 8 字型飄動提示），在手機被外殼包覆的狀態下，依然能提供直覺的操作暗示與強烈的視覺回饋。

## 🚀 互動流程 (User Journey)

1.  **喚醒星軌**：玩家點擊螢幕中央的玻璃按鈕啟動法杖，按鈕轉為「呼吸燈」狀態開始收音。
2.  **咒語充能**：對著手機麥克風說出四大元素咒語（如：「火元素」）。
3.  **引導揮動**：辨識成功後，螢幕爆發對應元素的高級光暈（如烈焰橘紅），並出現 8 字型搖晃動畫暗示。
4.  **魔法釋放**：玩家持法杖畫出「8」字型，手機強烈震動並觸發全白閃光。
5.  **星軌校準**：畫面浮現對應元素的「星座解鎖卡片」，完成互動儀式。

## 🛠️ 開發與安裝指南

本專案為純前端架構 (Vanilla JS + HTML/CSS)，無需配置後端伺服器或資料庫。

### 環境要求與測試限制 (⚠️ 重要)
由於 iOS 與 Android 瀏覽器的安全性限制，**語音辨識與陀螺儀功能必須在 `HTTPS` 協定下才能運作**。
* **不支援**：直接點擊兩下 `index.html` 開啟（`file:///` 協定）。
* **不支援**：無 SSL 憑證的區域網路 IP（例如 `http://192.168.1.X`）。

### 部署方式建議
請將本檔案上傳至具備 HTTPS 的伺服器空間，推薦使用以下免費服務進行展場部署：
1.  **GitHub Pages** (推薦，最穩定)
2.  **Vercel** 或 **Netlify**
3.  開發階段測試可使用 **ngrok** 或 **Cloudflare Tunnels** 進行本機穿透。
